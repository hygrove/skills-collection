# 学习记录格式（Learning Record Format）

学习记录住在 `./learning-records/`，使用顺序编号：`0001-slug.md`、`0002-slug.md` 等。惰性创建目录：只在写入第一条记录时才建。

它们是教学界对 ADR 的等价物：捕获非显而易见的教训、关键洞察，以及会引导未来会话的、已陈述的先验知识。它们被用来计算近端发展区（zone of proximal development）。

## 模板（Template）

```md
# {所学或确立之事的简短标题}

{1–3 句话：学到了什么（或确立了什么先验知识），以及为何它对未来会话重要。}
```

这就是整个格式。一份学习记录可以只有一个段落。价值在于记录*现在已知此事*以及*为何它改变了下一步该教什么*，而不是填完各个栏目。

## 可选栏目（Optional sections）

只有当它们确实增加价值时才包含。大多数记录不需要它们。

- **Status** frontmatter（`active | superseded by LR-NNNN`）：当先前的理解被证明是错的、并被取代时有用。
- **Evidence（证据）**：用户如何展示了该理解（一个被回答的问题、完成的练习、引用的先前经验）。当该主张可能被重新审视时有用。
- **Implications（含义）**：这对未来会话解锁了什么、或排除了什么。当非显而易见时值得记录。

## 编号（Numbering）

扫描 `./learning-records/` 找出已有的最大编号，加一。

## 何时写一份学习记录（When to write a learning record）

在以下任一为真时写一份：

1. **用户展示了对某件非平凡之事的真正理解**：不只是接触过，而是有证据显示他们能正确使用这个概念。这为下一步该教什么设了一个新的下限。
2. **用户披露了先验知识**："我已经知道 X。" 记录下来，这样未来会话不会重复教它。也记录所声称的*深度*。
3. **一个误解被纠正**：用户先前相信了某件错事，现在明白了为什么。这些价值很高：它们预测相关主题未来的绊脚石。
4. **使命因学习而转移**：用户发现他们在意的和以为的不同。交叉链接到 [[MISSION.md]] 并更新它。

### 什么不算数（What does _not_ qualify）

- 仅仅被覆盖的材料。覆盖不是学习。等证据。
- 任何已被简洁地捕获在 [[GLOSSARY.md]] 里作为术语定义的东西。不要重复。
- 逐次会话的活动日志。学习记录不是日记：它们是决策级的洞察。

## 取代（Supersession）

当一份后来的记录与一份较早的相矛盾时（用户的理解加深或纠正了），把旧记录标为 `Status: superseded by LR-NNNN`，而非删除它。理解如何演变的历史，其本身是有用的信号。
