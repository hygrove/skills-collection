# 阶段边界（Phase boundaries）

一个**阶段（phase）**是会话内部的一截工作：诘问（grilling-zh）、实现（implementation）、QA。定义刻意保持模糊：当你心想*"好了，这部分搞定了"*，一个阶段就结束了。

**阶段边界（phase boundary）**是两个阶段之间的空隙，也是这个决策唯一该落脚的地方。阶段中途没有决策可做：要么继续，要么把剩下工作拆给子代理。在阶段中途压缩（compact）上下文会让 agent 丢掉线索。

## 五个选项

| 选项 | 它做什么 |
| ------------ | --------------------------------------------------------------- |
| **Continue 继续** | 留在当前会话。完全不发生上下文切换。 |
| **`/clear`** | 清空上下文窗口，从零开始。 |
| **`/handoff-zh`** | 写一个可移植的 markdown 文件，并凭它随处播下一个新会话。 |
| **Subagent 子代理** | 把任务发到它自己的上下文窗口，拿一份报告回来。 |
| **`/compact`** | 压缩当前上下文，并用摘要播下一个全新会话。 |

## 决策树

在边界处从上往下走。第一个**是**胜出。

**1. 你能在这个会话里继续吗？** 两件事让答案为"是"：下一个阶段需要本阶段作为**一手来源（primary source）**，或者你还剩足够的 [smart zone](https://www.aihero.dev/ai-coding-dictionary/smart-zone)（约 150k token）装得下下一个阶段。诘问 → 实现是标准的"是"：实现想要的是逐字推理过程，而不是对它的摘要。继续不花任何代价、也不丢任何东西，所以把它排在任何其它选项之前先排除掉。

**2. 上下文与接下来要做的事无关吗？** 这个会话里的一切（探索、决策、死胡同）都是可丢弃的吗？如果是，**`/clear`**。这是棋盘上最便宜的一步：不花时间，把整个窗口还给你。`/clear` 也不是终局：旧会话仍然可以续接。

搞错这一项的代价是单向的。清掉一个*相关*的上下文，你就丢了你所构建之物背后的**为什么**，而无论怎么回读 diff 都找不回来。

**3. 你需要交接（hand off）吗？** `/handoff-zh` 范围很窄。你只在以下情况才需要它：

- 换到**新的运行环境（harness）**（Claude → Codex），
- 移动到**新的目录**或仓库，
- 把工作发给**同事**，
- 或者，在不打乱手头工作的前提下，fork 一个你在**阶段中途**发现的旁支任务。

这份清单就是全部条件。`/handoff-zh` 买到的是**可移植性**：一个能四处走的文件。如果没有东西要"走"，你就不需要它。

**4. 这个任务能离手（AFK）完成吗？** 它的范围是否收得足够紧，让你离开键盘、无需掌舵也能跑？那就把它发给一个**子代理**，并保持当前会话不动。自动化评审是标准情形：agent 读 diff 并回报，过程中你无需在场。

**5. 否则，`/compact`。** 相关上下文、同一运行环境、同一目录，而且你需要留在环里：决策树落在这里，而且经常落在这里。给它一句指令（`/compact 我们要 QA 这个区域`），好让摘要保留下一阶段需要的东西。

`/compact` 是**默认项，不是首选**。它落在最底部，是因为它上面的四个问题都更便宜或更精确。人们从这里起步时的失败模式是：一个新会话对一条被摘要压平的"决策"自信地判断错了。

## 一手来源与二手来源

除 **Continue** 外的每一个动作，都把**一手来源（primary source）**变成**二手来源（secondary source）**：会话原本的样子，被对它的一份摘要取代。这笔交易形态总是一样：

| 来源 | 信息量 | 噪声 | 腾挪空间 |
| --------------------------------- | ----------- | ----- | ------------ |
| 一手来源（Continue） | 完整 | 很多 | 很少 |
| 二手来源（`/compact`、`/handoff-zh`） | 有损 | 更少 | 很多 |

这就是为什么问题 1 排第一。只有当"留下"的代价大于它省下的，你才付出那笔有损的代价。

## 这些是判断性取舍

这些问题并不客观：每一个都带着主观品味，同一个边界在不同日子可能走向两个方向。价值在于**按顺序**提问，在边界处而不是在工作进行到一半时问。
